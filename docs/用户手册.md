# BoschCode 用户手册

## 快速开始

1. 启动应用，在主页点击 **New Project** 选择本地文件夹。
2. 在工作区选择 Agent 模式（Ask / Plan / Edit / Auto）。
3. 在设置 → 模型配置 中添加 Ollama 或云端 API 模型。

## 长期记忆

- 设置 → 记忆管理：审查、编辑、导出、压缩记忆。
- 向量索引损坏时，点击 **修复** 从 SQLite 重建索引。
- 聊天时自动检索相关记忆并注入上下文。

## Git 与变更

- 右侧栏 **Git** 面板：分支切换、stage/commit。
- **本次变更**：查看 Agent 产生的 diff，采纳或回滚。

## 安全与隐私

- 设置 → 隐私与安全：遥测、记忆加密、Shell/Push 确认。
- 审计日志：工作区右侧 **审计** 标签查看 Shell 命令记录。

## 故障排除

- **降级模式**：Ollama 不可达时仍可使用云端模型；语义搜索降级为关键词搜索。
- **数据库损坏**：设置 → 记忆管理 → 修复。
